# requirements-linux.txt — Linux/macOS-installable subset of requirements.txt
#
# Almighty AI is Windows-first. The following packages are Windows-only
# and are intentionally NOT listed here (they cannot build/install on Linux):
#   pyaudio, pycaw, comtypes, pywinauto, win10toast, pypiwin32/pywin32
#
# On non-Windows platforms `linux_shim.py` (imported first from main.py)
# stubs those modules so the app still imports and its cross-platform parts
# (UI, dashboard, TTS, tools) keep working. Windows-only *features* degrade
# gracefully instead of crashing.
#
# Versions are pinned to what was verified working in the reference venv
# (Python 3.13). Install with:
#   python -m venv .venv
#   .venv/bin/pip install -r requirements-linux.txt
#   .venv/bin/python -m playwright install chromium   # optional, browser tools
